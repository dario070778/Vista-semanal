# Vista semanal 2.5

Cambios principales:
- Las celdas se guardan por fecha real, no por día de la semana: las horas ya pasadas no reaparecen al día siguiente.
- Las palabras rápidas usan una clave de almacenamiento estable y migran las de versiones anteriores.
- Eventos importantes con un único marco dorado continuo para toda su duración.
- Planificación de eventos en fechas futuras.
- Eventos repetitivos: diario, lunes-viernes, semanal o días concretos.
- Los repetitivos se pueden cambiar solo para un día, desde una fecha o para toda la serie.
- Migración automática de la versión 1.3 conservando la semana actual y las palabras rápidas existentes.
